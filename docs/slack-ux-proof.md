# SignalDesk Slack UX Proof

Generated by `npm.cmd run slack:ux:proof`.

This artifact gives judges a repo-local receipt for the Slack surfaces that are hardest to inspect before the live sandbox is available: App Home onboarding, no-input help, slash-command proof checklist, App Home modals, and safe runtime error guidance.

## Demo Commands

- Short command: `/signaldesk demo`
- Full fallback: `/signaldesk Volunteer clicked a fake donor portal link at https://donor-login.example.bad/reset from 198.51.100.23, approved an MFA prompt, and pasted an access token. This may affect donor records and payroll.`
